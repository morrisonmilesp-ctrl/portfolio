# Portfolio

A static, dependency-free engineering portfolio template (HTML, CSS, JS) with dark mode and a responsive layout.

## Customize

1. Edit `index.html`: replace every placeholder ("Your Name", `your-username`, `you@example.com`, project and job entries).
2. To add a resume download, put the file at `resume.pdf` in the repo root and add a button linking to it in the hero.
3. Tweak colors in the `:root` and `[data-theme="dark"]` blocks at the top of `styles.css`.

## Preview locally

Open `index.html` in a browser, or run `python -m http.server` and visit http://localhost:8000.

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings > Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`.
3. Your site appears at `https://<username>.github.io/<repo>/`. Name the repo `<username>.github.io` to get `https://<username>.github.io/` instead.
